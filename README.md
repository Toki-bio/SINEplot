GitHub Description:
Interactive visualizer for SINE subfamily classification using raw ssearch36 bitscores. Generates a dynamic 2D plot where each SINE is positioned by its similarity to reference subfamilies—supports subfamily assignment mode and RGB ternary blending, with smart downsampling, clustering, and clipboard-enabled selection.

Why: Turns raw alignment scores into an intuitive, interactive visualization for SINE comparative analysis.
How: Run python SINEplot.py score.txt -o plot.html; explore assignments, confidence, and bitscores interactively in your browser.
